# Walkthrough: mask, review, restore

The README animation is recorded from the real browser build running the Python engine in Pyodide. Caption bars explain four steps; the evidence panels are unmodified screenshots. Holds are editorial timing, not a performance benchmark.

1. Paste a synthetic support record. `10.20.3.7` occurs twice and receives `[[IP_1]]` both times. The name, email and other IP are detected.
2. Review what remains. The fictional project code `Anka-42` is deliberately not detected automatically. Add it through **Bunu da maskele**.
3. Choose **Maskele ve kopyala**. Six replacements correspond to five unique original values in this session.
4. Paste a manually written sample reply. Five tokens restore to their originals locally. The text explicitly labels the reply as an example with no LLM call.

All input values are invented fixtures. No customer record, real credential or provider response appears in the recording. The example does not establish that arbitrary sensitive values will be detected. Review is part of the workflow.
